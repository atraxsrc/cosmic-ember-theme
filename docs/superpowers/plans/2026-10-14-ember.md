# Ember Pair Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build cosmic-ember-theme (dark, "Ember") and cosmic-emberday-theme (light, "Ember Day"), one design in two halves, each with the full sibling component set and five wallpapers rendered by a script.

**Architecture:** Each repo is seeded from the closest template (Ember from cosmic-tokyonight-theme, Ember Day from cosmic-tokyoday-theme), renamed, then every component rewritten from the spec's palette tables. Tasks are listed per half with the exact file contents, so the two halves can be built in parallel; the icon-theme task and the wallpaper pipeline are shared.

**Tech Stack:** COSMIC RON, COSMIC Terminal schemes, bash, Lua, YAML, JSONC, Firefox WebExtension theme + userChrome CSS, Python 3, ImageMagick 6 (`convert`).

**Spec:** `cosmic-ember-theme/docs/superpowers/specs/2026-10-14-ember-design.md` (one spec for both repos; Ember Day's tasks read it from the sibling path).

## Review Focus

- A ron missing a frosted key or the text tint: the frosted slider resets text to white (libcosmic pull 1450). Tasks N3 and D3 grep every key.
- A terminal scheme without `background`: the pane follows the window. Tasks N4 and D4 grep for it.
- A leftover `TokyoNight`, `tokyonight`, `TokyoDay` or `tokyoday` in a script variable: the installer fetches the wrong pack. Tasks N1, D1 and V1 grep the tree.
- A readable colour under 4.5:1: the contrast script fails the build. Tasks N2 and D2.
- A wallpaper whose base does not match the window colour: windows look cut out. Tasks N14 and D14 sample the corners.

### Task W1: wallpaper pipeline script (dark repo, after Task N1)

**Files:**
- Create: `cosmic-ember-theme/scripts/wallpaper.sh`; Task D14 copies it into `cosmic-emberday-theme/scripts/`.

**Interfaces:**
- Produces: `scripts/wallpaper.sh MODE SOURCE OUT` where MODE is `night` or `day`, SOURCE a path into cool-wallpapers, OUT the png to write at 3840x2160.

- [ ] **Step 1: Write the script**

```bash
#!/usr/bin/env bash
# Render one Ember wallpaper from a source image with ImageMagick 6.
#
#   ./scripts/wallpaper.sh night ../cool-wallpapers/omarchy/the-greek/the-greek-bg1-3840x2160.jpg backgrounds/ember-eagle.png
#   ./scripts/wallpaper.sh day   ../cool-wallpapers/omarchy/the-greek/the-greek-bg1-3840x2160.jpg backgrounds/emberday-eagle.png
#
# The source is converted to grey, inverted when its mean luminance is above
# 0.5 for night (ink-on-paper sources) or below 0.5 for day (dark sources),
# then mapped through a 256-row colour lookup built from stacked gradients:
#   night: #15171C > #2A2F38 > #7C8290 > #E8713A > #F1D9C8  (ember on highlights only)
#   day:   #2B2E36 > #6B6F78 > #A4441A > #D4CFC6 > #E9E6DF
# The window end of the lookup is a flat band (night: the darkest 19 percent,
# day: the lightest 20 percent) so a source background that is not pure
# black or white still lands exactly on the window colour.
# Output is cover-cropped and centred at 3840x2160, alpha dropped.
set -euo pipefail

mode="${1:-}"; src="${2:-}"; out="${3:-}"
[[ "$mode" == night || "$mode" == day ]] || { echo "usage: $0 night|day SOURCE OUT"; exit 1; }
[[ -f "$src" ]] || { echo "no source at $src"; exit 1; }

tmp="$(mktemp -d)"; trap 'rm -rf "$tmp"' EXIT
if [[ "$mode" == night ]]; then
  convert -size 1x48 xc:'#15171C' -size 1x42 gradient:'#15171C-#2A2F38' -size 1x70 gradient:'#2A2F38-#7C8290' -size 1x60 gradient:'#7C8290-#E8713A' -size 1x36 gradient:'#E8713A-#F1D9C8' -append "$tmp/clut.png"
else
  convert -size 1x100 gradient:'#2B2E36-#6B6F78' -size 1x50 gradient:'#6B6F78-#A4441A' -size 1x40 gradient:'#A4441A-#D4CFC6' -size 1x15 gradient:'#D4CFC6-#E9E6DF' -size 1x51 xc:'#E9E6DF' -append "$tmp/clut.png"
fi

mean="$(convert "$src" -resize 400x400 -colorspace Gray -format '%[fx:mean]' info:)"
neg=()
if [[ "$mode" == night ]]; then
  (( $(echo "$mean > 0.5" | bc) )) && neg=(-negate)
else
  (( $(echo "$mean < 0.5" | bc) )) && neg=(-negate)
fi

mkdir -p "$(dirname "$out")"
convert "$src" -resize 3840x2160^ -gravity center -extent 3840x2160 -colorspace Gray "${neg[@]}" "$tmp/clut.png" -clut -alpha off -strip "$out"
echo "$out  (mean $mean, ${neg[*]:-as is})"
```

Note: with `set -u`, `"${neg[@]}"` on an empty array is fine in bash 4.4 and later (Pop!_OS 24.04 ships 5.2).

### Task N2: Contrast script

**Files:**
- Modify or create: `scripts/contrast.py`

**Interfaces:**
- Produces: `python3 scripts/contrast.py` prints the README palette table (Role, swatch + name, Hex) on stdout, ratios on stderr, exit 1 if a readable role is under 4.5:1 on the window.

- [ ] **Step 1: Write the script**

```python
#!/usr/bin/env python3
"""Ember palette table for the README (stdout) with contrast ratios on stderr.
Exit 1 if a readable role is under 4.5:1 on the window background."""
import sys

WINDOW = "#15171C"
PANE = "#1B1E24"

SURFACES = [
    ("Background", "Night", ["#15171C"]),
    ("Containers", "Soot / Pane", ["#22262E", "#1B1E24"]),
    ("Terminal", "Pane, opaque", ["#1B1E24"]),
]

# (role, name, hex, reads) where reads=True means a user reads it as text.
ROLES = [
    ("Text", "Fog", "#D6D9E0", True),
    ("Accent", "Ember", "#E8713A", True),
    ("Success", "Moss", "#8FB58A", True),
    ("Warning", "Amber", "#D9A441", True),
    ("Error", "Brick", "#D85A5A", True),
    ("Blue", "Slate blue", "#7FA3C7", True),
    ("Magenta", "Heather", "#B08BC4", True),
    ("Cyan", "Verdigris", "#7FB7B3", True),
    ("Muted", "Muted", "#7C8290", False),
    ("Comment", "Comment", "#5A6070", False),
]


def swatch(hexv):
    hx = hexv.lstrip("#").lower()
    return f"![{hexv}](https://placehold.co/12x12/{hx}/{hx}.png)"


def lum(h):
    r, g, b = (int(h[i:i + 2], 16) / 255 for i in (1, 3, 5))
    f = lambda c: c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4
    return 0.2126 * f(r) + 0.7152 * f(g) + 0.0722 * f(b)


def ratio(a, b):
    la, lb = sorted((lum(a), lum(b)), reverse=True)
    return (la + 0.05) / (lb + 0.05)


def main():
    bad = []
    print("| Role | Color | Hex |")
    print("|------|-------|-----|")
    for role, name, hexes in SURFACES:
        hx = " / ".join(f"`{x}`" for x in hexes)
        print(f"| {role} | {swatch(hexes[0])} {name} | {hx} |")
    for role, name, hexv, reads in ROLES:
        w, p = ratio(hexv, WINDOW), ratio(hexv, PANE)
        print(f"| {role} | {swatch(hexv)} {name} | `{hexv}` |")
        print(f"  {role}: {w:.1f}:1 on window, {p:.1f}:1 on pane", file=sys.stderr)
        if reads and w < 4.5:
            bad.append((role, w))
    for role, w in bad:
        print(f"FAIL {role} {w:.1f} < 4.5 on window", file=sys.stderr)
    return 1 if bad else 0


if __name__ == "__main__":
    sys.exit(main())
```

### Task D2: Contrast script

**Files:**
- Modify or create: `scripts/contrast.py`

**Interfaces:**
- Produces: `python3 scripts/contrast.py` prints the README palette table (Role, swatch + name, Hex) on stdout, ratios on stderr, exit 1 if a readable role is under 4.5:1 on the window.

- [ ] **Step 1: Write the script**

```python
#!/usr/bin/env python3
"""Ember Day palette table for the README (stdout) with contrast ratios on stderr.
Exit 1 if a readable role is under 4.5:1 on the window background."""
import sys

WINDOW = "#E9E6DF"
PANE = "#DDD9D1"

SURFACES = [
    ("Background", "Stone", ["#E9E6DF"]),
    ("Containers", "Linen / Pane", ["#E2DED6", "#DDD9D1"]),
    ("Terminal", "Pane, opaque", ["#DDD9D1"]),
]

# (role, name, hex, reads) where reads=True means a user reads it as text.
ROLES = [
    ("Text", "Ink", "#2B2E36", True),
    ("Accent", "Ember", "#A4441A", True),
    ("Success", "Moss", "#4C6B45", True),
    ("Warning", "Amber", "#8A5E12", True),
    ("Error", "Brick", "#9E3A3A", True),
    ("Blue", "Slate blue", "#2F5C8A", True),
    ("Magenta", "Heather", "#6E4E8C", True),
    ("Cyan", "Verdigris", "#2E6E6A", True),
    ("Muted", "Muted", "#6B6F78", False),
    ("Comment", "Comment", "#8C9099", False),
]


def swatch(hexv):
    hx = hexv.lstrip("#").lower()
    return f"![{hexv}](https://placehold.co/12x12/{hx}/{hx}.png)"


def lum(h):
    r, g, b = (int(h[i:i + 2], 16) / 255 for i in (1, 3, 5))
    f = lambda c: c / 12.92 if c <= 0.03928 else ((c + 0.055) / 1.055) ** 2.4
    return 0.2126 * f(r) + 0.7152 * f(g) + 0.0722 * f(b)


def ratio(a, b):
    la, lb = sorted((lum(a), lum(b)), reverse=True)
    return (la + 0.05) / (lb + 0.05)


def main():
    bad = []
    print("| Role | Color | Hex |")
    print("|------|-------|-----|")
    for role, name, hexes in SURFACES:
        hx = " / ".join(f"`{x}`" for x in hexes)
        print(f"| {role} | {swatch(hexes[0])} {name} | {hx} |")
    for role, name, hexv, reads in ROLES:
        w, p = ratio(hexv, WINDOW), ratio(hexv, PANE)
        print(f"| {role} | {swatch(hexv)} {name} | `{hexv}` |")
        print(f"  {role}: {w:.1f}:1 on window, {p:.1f}:1 on pane", file=sys.stderr)
        if reads and w < 4.5:
            bad.append((role, w))
    for role, w in bad:
        print(f"FAIL {role} {w:.1f} < 4.5 on window", file=sys.stderr)
    return 1 if bad else 0


if __name__ == "__main__":
    sys.exit(main())
```
